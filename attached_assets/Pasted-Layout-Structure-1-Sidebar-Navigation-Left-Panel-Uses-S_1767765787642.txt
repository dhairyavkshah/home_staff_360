Layout Structure
1. Sidebar Navigation (Left Panel)
Uses Shadcn's Sidebar component with:
•	Header: Logo + App name ("Home Staff 360 - Admin Portal")
•	Navigation Menu: List of pages with icons and active state highlighting
•	Footer: Admin profile (avatar, name, role) + Sign out button
2. Main Content Area (Right Panel)
•	Page-specific content with consistent padding (p-6)
•	Responsive grid layouts for cards and data
________________________________________
Pages & Features
Page	Route	Features
Dashboard	/admin/dashboard	Stats cards (Total Users, Home/Staff users, Quick Actions grid, Quick Stats panel
Home Users	/admin/users	User list with search, filters (status, plan), DataTable with pagination, View/Delete actions
Staff Accounts	/admin/staff-accounts	Similar to users, filtered for STAFF type
Connections	/admin/engagements	Connect relationships between users
Invitations	/admin/invitations	Pending connect requests tracking
Activity Logs	/admin/activity	Audit trail of all admin actions
Admin Users	/admin/admins	Manage admin accounts (superadmin only)
Settings	/admin/settings	Platform configuration
Login	/admin/login	Email + password authentication
________________________________________
Key Components Used
StatsCard        - Metric display with icon, value, description, trend indicator
DataTable        - Sortable, paginated table with column definitions
StatusBadge      - Colored badges for status display
LoadingSpinner   - Loading states
AlertDialog      - Confirmation modals (delete actions)
DropdownMenu     - Action menus (view, edit, delete)
Select           - Filter dropdowns
Input            - Search fields
Card             - Content containers
________________________________________
Authentication Flow
1.	Login: Email + password → JWT access token + refresh token
2.	Protected Routes: Check isAuthenticated via AuthContext
3.	Role-based Access: Superadmin can manage other admins
4.	Auto-refresh: Tokens refresh automatically before expiry
________________________________________
API Endpoints Pattern
GET    /api/admin/dashboard/stats   - Dashboard metrics
GET    /api/admin/users             - List users (paginated)
GET    /api/admin/users/:id         - User detail
PATCH  /api/admin/users/:id         - Update user
DELETE /api/admin/users/:id         - Delete user
GET    /api/admin/admins            - List admins
POST   /api/admin/admins            - Create admin
GET    /api/admin/logs              - Activity logs
POST   /api/admin/login             - Admin login
GET    /api/admin/me                - Current admin profile
________________________________________
Design Patterns
•	Icon Halos: Circular backgrounds with glassmorphism (icon-halo-primary, icon-halo-success, etc.)
•	Sharper Corners: Cards use rounded-lg, buttons/inputs use rounded-md
•	Consistent Spacing: gap-4 for grids, gap-6 for sections
•	Dark Mode Support: All components use CSS variables for theming
