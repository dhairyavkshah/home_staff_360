Samsung Galaxy S21 FE – Issue Notes

Landing Page
On the landing page, when navigating to the language selection screen, the search text box is displayed outside the visible screen area, making it difficult to search for and select a language.

Home User (App Permissions)
After clicking the “Allow” button, if the user subsequently clicks “Don’t allow”, the “Try again” button is shown instead of the “Allow” button on steps 1, 3, and 4.

Home User (App Permissions)
From a usability perspective, the “Continue” button should be enabled only after all required permissions are granted on the App Permissions page. Otherwise, this may cause issues when accessing the camera, notifications, and other essential features.

Internet Connectivity Handling
When the internet connection is unavailable, no warning or message is displayed, even though an active connection is required to synchronize Home and Staff data in real time.
(Product Owner response: Not applicable, as this is an offline, device-local application.)

Home User (Overall Setup Screen)
On the Overall Home User setup screen, when clicking on any text box, the UI does not render properly. The content below the selected field becomes invisible, and a blank white space appears instead.

Home User (Currency & Country Selection)
While selecting the currency or country from the dropdown, the search text box appears beyond the visible screen area, making it difficult to search for and select the desired option.

Home User (Staff → Add Member)
The user is completely blocked after clicking on any text box in the “Add Staff Member” screen, as the input fields become invisible, preventing further editing.

Home User (Reports)
The application crashes and closes when the user clicks on the “Send Report” option from the Reports section.

Home User (Overview → Payable)
In the Overview → Payable section, only the integer value should be displayed. Currently, the amount is shown as “1,666.67” instead of “1,666”.

Home User (Staff → Search)
In the Staff section, the “Clear” and “Close” buttons are displayed outside the search text box. This disrupts the search UI, particularly when an incorrect search term is entered.

Laundry Details (Service Type)
The user is blocked and unable to select any cloth types from the Laundry Details service type.
