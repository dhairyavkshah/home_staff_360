# Home Staff 360 Release Notes

## Offline edition

- Works from the application bundle without a hosted server.
- Stores profiles and operational records locally on the device.
- Starts new users directly in local setup and onboarding.
- Keeps local profile name and photo editing.
- Removes phone sign-in, OTP verification, SMS invitations, online accounts,
  collaboration, chat, remote notifications, server sync, subscriptions, ads,
  maintenance controls, and web administration.
- Keeps user-controlled local backup, restore, and export features.
